\section*{Ethics Statement}
\label{sec:ethics}

The corpus builder fetches a seed Wikipedia page plus a small, bounded number of linked pages, with retry-and-backoff rather than aggressive re-fetching; a production deployment should prefer the Wikimedia REST API or a static dump over live scraping. Wikipedia text is CC~BY-SA; embedded images carry heterogeneous, some non-free, licenses, so the screenshots/tiles produced are derivative works we do not release. Synthetic questions (\S\ref{sec:contrastive}) are VLM-produced and unverified, and should be labeled as such if released. No human subjects or user study.
