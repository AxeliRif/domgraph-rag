Visual retrieval-augmented generation renders documents as images and lets a vision-language model read them directly, avoiding the losses of OCR and text extraction. Existing systems cut the rendered page on a fixed pixel grid, blind to content, so a table or a paragraph can be split across tiles and the retriever must recover boundaries the renderer already knew. We observe that on the web this segmentation is free: the browser's layout engine exposes every element's bounding box before a single pixel is cropped. We introduce \textbf{DOM-Graph RAG}, which tiles pages along their own DOM elements, organizes the tiles into a multigranular evidence graph, and reads them with a contrastively fine-tuned VLM. Against a blind fixed-height grid at equal render width, DOM-guided tiling reaches a given page's content with substantially fewer pixels and a higher answer-attachment rate, and our fine-tuned reader nearly doubles top-1 retrieval on held-out articles. The full pipeline, including a budgeted graph controller for evidence selection, is open-sourced; \S\ref{sec:experiments} reports where each component currently stands, including a negative result for the controller on cross-page questions.
