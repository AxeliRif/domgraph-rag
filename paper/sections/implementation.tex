\section{Implementation}
\label{sec:implementation}

The pipeline is implemented in Python and released as an open, modular package: rendering and geometric extraction via headless Chromium (Playwright); tiling and patching over Pillow crops of a full-page screenshot; graph construction and corpus composition with \code{networkx}; the reader VLM served either through Ollama (\texttt{qwen3-vl}, the default, requiring no GPU or heavy dependencies) or through Hugging Face \code{transformers} (\code{Qwen2-VL-7B-Instruct}) when LoRA fine-tuning or direct access to hidden states is needed; hard-negative mining with \code{scikit-learn}'s TF-IDF and cosine similarity (with a dependency-free fallback); and contrastive LoRA fine-tuning with \code{peft} and \code{torch}, LoRA target modules discovered by introspecting the loaded model rather than hard-coded, so the code does not silently no-op if an internal module-naming convention changes across \code{transformers} versions. An accompanying Jupyter notebook runs every stage end-to-end against live Wikipedia pages, including interactive graph visualizations (state-colored, with tile images embedded in node tooltips) built with \code{pyvis}. Two dependency-light smoke tests exercise the geometric pipeline (DOM extraction through XML export) and the synthetic-QA/mining/dataset-assembly stages against a bundled local HTML fixture, requiring neither network access nor a real VLM or GPU, so the core pipeline's correctness can be checked in CI without any external service.
